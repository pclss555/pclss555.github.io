记录一下第一次使用AndroidStudio编写Xposed模块。

一、 导入外部库

导入外部库de.robv.android.xposed之后，才能使用xposed的api

1. build.gradle（app）

添加

2. settings.gradle

添加
表明依赖下载地址

点击同步sync，此时外部库中就能看到de.robv.android.xposed:api:82

二、 编写文件

1. AndroidManifest.xml

三个meta-data放在<application> </application>之间，把原先的代码挪到<application>内

2. scope.xml

新建res/xml/scope.xml，添加作用范围（包名）

3. 入口类Hook

右键java-com.example.XposedDemo –> 新建Java类Hook

4. assets

右键main新建–>Folder–>Assets Folder，创建xposed_init，说明入口类Hook

问题：

1. Default Activity Not Found

可以通过选择运行左边的左边的app > edit configuration 把Launch 改成 Nothing

2. Android Studio 的增量安装

as偷懒，导致修改后的模块并没有在手机端更新。

解决：点击app旁边的下箭头∨ –> 编辑配置 –> 勾选“Always install with package manager
(disables deploy optimizations on Android 11 and later)” –> 应用
